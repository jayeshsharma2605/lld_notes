Source: [Concept && Coding — Low Level Design playlist](https://www.youtube.com/playlist?list=PL6W8uoQQ2c61X_9e6Net0WdYZidm7zooW)

> These are independently written study notes, not video transcripts. The diagram in each file is a reusable problem-solving flow; topic-specific UML and sequence diagrams are included where appropriate in the consolidated chapter notes.
